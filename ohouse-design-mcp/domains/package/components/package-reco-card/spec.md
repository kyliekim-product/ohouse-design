# Package Reco Card (reco-card)

글린다 패키지할인 메인 화면에서 *구매 조건 완성*을 유도하는 카테고리 추천 카드. 팀 내부 명칭 **"지면3"**.

> **3계층 경계**
> - **ODS atoms**: Chip·Text 등 — ODS Library 참조
> - **도메인 고유 조합** — 본 문서 (조건 단계별 문구·추천 카테고리 노출 규칙)

---

## 1. 정체성·역할

- 패키지 메인 화면 상단(ATF 툴바 아래)에 위치하는 가이드 카드
- **목적**: 구매 조건(서로 다른 카테고리 5개 이상·가구 2개 필수)을 아직 못 채운 유저에게 다음에 담을 카테고리를 추천
- ⚠️ **판단 기준 = 패키지에 *추가된* 상품** — 선택/체크 상태 기준이 아님. 글린다에서 가장 자주 헷갈리는 지점 [출처: _commerce-ingest §2 트랙 고유 디자인 원칙]

## 2. 구성

- **안내 문구**: 현재 진행 단계에 따라 동적으로 변경 (§3 매트릭스)
- **추천 카테고리 칩 영역**: 다음에 담을 카테고리 칩 + 검색칩
- 클릭 시 해당 카테고리가 선택된 상태로 상품 리스트 화면 진입

## 3. 단계별 추천 매트릭스

> 가구 수·총 카테고리 수에 따라 문구와 노출 카테고리가 분기. 수치는 도메인 운영 규칙.

| 가구 수 | 총 카테고리 | 문구 | 노출 카테고리 |
|---|---|---|---|
| 0개 | any | 먼저, 가구 1개를 추가하세요 (0/2) | 가구 카테고리만 |
| 1개 | any | 가구 1개만 더 추가하세요 (1/2) | 이미 추가된 카테고리 제외, 가구 카테고리 |
| 2개+ | 2개 | 3개 카테고리 더 추가하면 돼요! | 이미 추가된 카테고리 제외 |
| 2개+ | 3개 | 이제 2개 카테고리 남았어요! | 이미 추가된 카테고리 제외 |
| 2개+ | 4개 | 거의 다 왔어요. 마지막 1개만 더! | 이미 추가된 카테고리 제외 |
| 2개+ | 5개+ | 구매조건을 모두 채웠어요 / 더 담을수록 할인이 커져요 | 현재 유지 |

[출처: _commerce-ingest-raw §3-2, [추천되는 카테고리 로직 COMMPO-1650](https://ohouse.atlassian.net/browse/COMMPO-1650)]

## 4. 카테고리 칩 노출 규칙

- **접힌 상태**: 2줄까지 노출 + 마지막에 검색칩
- **펼친 상태(더보기)**: 4줄까지 노출 + 마지막에 검색칩
- **검색칩**: 항상 1개만 노출
- 검색칩 클릭 → 상품 리스트 화면 진입, 검색창 포커스 + 키보드 노출

[출처: _commerce-ingest-raw §3-2]

## 5. 동작

| 영역 | 액션 |
|---|---|
| 카테고리 칩 | 해당 카테고리가 선택된 상태로 상품 리스트 화면 진입 |
| 검색칩 | 상품 리스트 화면 진입 + 검색창 포커스/키보드 |
| 더보기 토글 | 칩 영역 접힘(2줄) ↔ 펼침(4줄) 전환 |

## 6. 미해결·판단 필요

- [ ] 칩 노출 줄 수(접힘 2줄·펼침 4줄)가 화면 너비별로 고정인지, variant가 있는지 확인
- [ ] "구매조건 충족 후"의 reco-card 노출 여부 — progress-bar의 "더 담기" 유도와 역할 중복 가능성
- [ ] Figma 대표 node URL

## 7. LLM 작업 시 주의사항

- ⚠️ **판단 기준은 추가된 상품** — 선택/체크 기준 아님 (§1)
- ⚠️ 문구는 고정값 X — 가구 수·총 카테고리 수 조합으로 분기 (§3)
- ⚠️ 검색칩은 항상 1개, 칩 영역 마지막에 위치
- ⚠️ 수치보다 정책 — 정확한 spacing·typography는 ODS MCP 또는 Figma 실측 우선

## ODS atoms 매핑

- ODS Chip (카테고리 칩·검색칩 — variant TBD)
- ODS Text 또는 직접 typography (안내 문구)

정확한 컴포넌트·variant는 ODS MCP `get_component` 호출로 확인. 본 문서는 정책·맥락 단위.
