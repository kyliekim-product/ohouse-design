# 장바구니 CTA/개별상품 가격·혜택 인지 개선

## 배경
- 장바구니 CTA가 총 금액·상품 개수·구매 버튼 중심으로 구성되어 할인 정보 확인 불가
- 쿠폰 사용 건수 전년 대비 32% 상승했으나 장바구니 내 혜택 체감도 부족
- 장바구니→주문서 CVR 2024년 대비 2.6%p 하락

## 가설
장바구니에서 쿠폰 할인 금액·결제 예정금액을 제공하고 바텀시트로 상세 할인내역을 보여주면, 유저는 투명한 결제 가격 정보를 기반으로 구매 확신을 얻고 결제 행동으로 이어진다.

## 해결 방향
- CTA에 **선택 상품 수·총 상품 금액·총 할인 금액·결제 예정 금액** 4종 직접 노출
- 바텀시트로 상세 할인 내역 제공
- 상품 옵션별 쿠폰 할인가 표기 및 실시간 재계산
- 넛지 문구: "최대 할인 쿠폰 자동 적용" (이전 "N원 쿠폰 할인됨" 폐기)

## 결과 (B Winner)

| 지표 | 변화 | 유의성 |
|---|---|---|
| 유저 기반 장바구니 구매전환율 | 29.0% → 29.5% **(+1.73%)** | p<0.001 |
| 액션 기반 장바구니 구매전환율 | 3.6% → 3.7% (+2.49%) | p<0.001 |
| 장바구니→주문서 전환율 | 43.7% → 42.5% (-2.56%) | p<0.001 |
| 주문서→주문완료 전환율 | 75.8% → 77.7% (+2.50%) | p<0.001 |
| 전체 구매전환율 | 36.9% → 37.0% (+0.04%) | p=0.906 |
| KR GMV/customer | +0.49% | p=0.603 |

→ 장바구니 기반 구매전환 유의 상승, 가드레일 영향 없음 → **B 100% 롤아웃**

## 인사이트

**장바구니에 쿠폰 할인가를 노출 → 구매 의사결정 시점이 주문서에서 장바구니로 앞당겨짐. 장바구니가 '담아두는 곳'에서 '판단하는 곳'으로 확장됨.**

- 가격 확인 목적의 주문서 진입은 줄고, 주문서 진입 유저는 이미 구매 의사가 굳어진 상태 → 완료 전환율 동반 상승
- 이탈 지점이 주문서에서 장바구니로 이동했을 가능성도 있으나, 전체 구매전환율 상승을 보면 이탈보다 구매 확신 전환 비중이 더 컸음
- 후속: 쿠폰 다운로드·배송비 넛지·할인 알림 등 가격 기반 액션 동선 마련됨

## UT 사전 인사이트
- 장바구니에서 쿠폰 할인이 '보이는 것' 자체가 할인 인지 강화 + 구매 의사결정에 긍정적 영향
- 기존엔 쿠폰 존재 확인 위해 주문서 반복 진입 → 장바구니에서 즉시 확인 가능해져 탐색 부담 감소
- 장바구니에 상품 많이 담거나 쿠폰 적극 활용하는 유저에게 **재확인 트리거**로 작동 → 구매 확신 강화

## 디자인 고려사항
1. **CTA 구조** — 영역 덜 차지하지만 정보 복잡 vs 영역 차지하지만 정보 단순 → **후자 win** (개별 상품 가격 우측 정렬과 시선 흐름 일치 + 직관적)
2. **CTA 넛지 문구** — "N원 쿠폰 할인됨" vs "최대 할인 쿠폰 자동 적용" → **후자 win** (할인액 자체보다 "최대 자동 적용" 메시지가 더 유의미)
