# 장바구니 선택 UX 개선 (체크박스 default + 선택 정보 저장)

## 배경
- "전체 선택을 해제하고 구매하려는 상품을 다시 선택하는 것이 불편하다"는 지속적 VOC
- 장바구니 진입 시 체크박스 기본값과 선택 정보 저장 정책을 동시 검증 필요

## 가설
1. 기본값을 '모두 해제'로 변경하면 불필요한 '해제 후 재선택' 행동이 줄어 주문서 진입률 상승
2. 선택 정보를 저장하면 재방문 시 반복 선택의 번거로움이 사라져 이탈률 감소
3. 선택한 상품이 없을 때 구매 버튼을 비활성화하면 불필요한 에러 경험 차단

## 해결 방향
4분기 분기 설계 (각 25%):
- **A**: 전체 선택 default (기존)
- **B**: 전체 선택 default + 선택 정보 저장
- **C**: 전체 선택 해제 default + 선택 정보 저장
- **D**: 전체 선택 해제 default ← **Winner**

## 결과 (D Winner / 전환 지표 inconclusive)

| 지표 | B | C | D |
|---|---|---|---|
| 유입고객당 GMV | **+3.2% (p=0.031) ✅** | +3.5% (p=0.072) | +2.8% (p=0.067) |
| 구매자 전환율 | +0.92% (p=0.070) | +0.38% (p=0.454) | +0.28% (p=0.574) |
| 장바구니 → 주문서 전환율 | +0.20% (p=0.605) | -0.20% (p=0.608) | -0.21% (p=0.592) |
| 장바구니 모두선택/상품선택 클릭수 | 모두 유의 하락 | 유의 하락 | 유의 하락 |
| 30-50개 담은 유저 구매전환율 | **유의 상승** | - | - |

→ 전환/매출 유의미 차이 없으나, 기존 전체 선택 default에 대한 불편 해소 + 유저 '의도 기반 선택' UX 명확화를 위해 **D안 런칭**.

## 인사이트

**선택 UX 개선 효과는 '상품을 많이 담은 유저(30-50개)'에서 더 크게 작용. 구매 결정보다는 선택 효율·피로도 감소에 더 직접적 영향.**

- B(전체선택 + 정보저장) 안에서 30-50개 담은 유저 구매전환율 유의 상승 → DA는 B 런칭 제안
- 그러나 데이지(PD) 판단: 의도 기반 선택 UX 명확화 우선 → D 런칭 (전환 효과 X 인정하고 UX 가치만 취함)
- **이 실험은 '데이터 vs UX 가치' 중 후자를 우선한 사례**
- 후속: 마지막 담은 상품 선택, 당일 담은 상품 선택 등 부분 자동 선택 iteration 예정

## 디자인 고려사항
1. **체크박스 default**: 전체 선택은 빠르지만 불편 VOC ↑, 전체 해제는 마찰 ↑지만 의도 명확. → 전체 해제 + 부분 자동 선택(최근 담은 N개) 방향 검토
2. **선택 정보 저장**: 저장 시 재방문 마찰은 낮아지나, 의도 변화 시 혼란 가능 → 시간 윈도우(예: 당일/24h 내)로 제한
