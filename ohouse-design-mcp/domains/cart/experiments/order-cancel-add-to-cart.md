# 주문취소 후 장바구니 담기

## 배경
- 주문 취소 후 30일 이내 같은 상품을 재주문하는 비율 37%
- 그러나 재구매를 위해서는 **주문 상세 → PDP → 옵션 선택**의 3단계 과정을 거쳐야 함
- 주문 취소율 8% (주당 5만건 / 70만건) — 적지 않은 규모
- 취소 직후가 재구매 의도가 가장 높은 시점인데 이를 활용하지 못하고 있음

## 가설
주문 취소 완료 화면에서 즉시 '장바구니 담기' 버튼을 제공해 기존 옵션을 그대로 담을 수 있도록 하면, 재구매 경로가 단축되고 취소 직후 발생하는 전환 손실을 최소화할 수 있다.

## 해결 방향
- 주문 취소 완료 화면에서 동일 상품·동일 옵션을 장바구니에 바로 담을 수 있는 버튼 제공
- PDP 재방문·옵션 재선택 단계 생략

## 결과 (B Winner)

| 지표 | 변화 | 유의성 |
|---|---|---|
| 구매자 전환율 | +0.29% | p=0.47 (검정력 부족) |
| 주문 취소 후 재구매 유저 비율 | +1.14% | p=0.13 |
| 주문 취소 후 장바구니 담기 유저 비율 | **+13.93%** | p=0 |
| 장바구니 to 구매전환율 | **+3.38%** | p=0.01 |
| 실험 유저 대비 PDP 구매기대 액션 유저 비중 | -5.28% | p=0 |

→ 모수 7.7만명으로 구매자 전환율은 검정력 부족이나, 핵심 액션·장바구니→구매 전환율이 유의 상승 → **B 런칭**.

## 인사이트

**취소 직후 = 재구매 의도 최고조 시점. 마찰 단계만 제거해도 장바구니 전환율 유의 상승. PDP 지표 하락은 손실이 아닌 '여정 단축' 효과.**

- 취소 상품의 PDP 재방문 여정이 생략되면서 PDP 관련 지표는 하락
- 그러나 PDP 조회 상품 개수는 유의하게 변하지 않아 다른 상품 탐색은 줄지 않았음 → 재구매 여정만 단축된 것
- 이커머스 일반론: 부정 이벤트(취소·환불) 직후가 오히려 회복 동선 설계의 골든타임

## 디자인 고려사항
1. **CTA 우선순위**: 취소 완료 페이지에서 '장바구니 담기' vs '비슷한 상품 보기' vs '환불 진행 상태' 중 어느 액션이 1순위인가 → 재구매 의도가 명확한 동일 상품 담기 우선
2. **옵션 자동 채우기**: 기존 주문의 옵션을 그대로 가져와야 마찰 제거 효과 발생. 옵션 재선택 강제 시 효과 반감
