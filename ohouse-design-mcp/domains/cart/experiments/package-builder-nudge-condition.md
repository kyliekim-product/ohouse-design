# 패키지빌더 지면5 노출조건 변경 (장바구니-글린다 일원화)

## 배경
- 장기적 목표인 패키지-장바구니 경험 일원화 일환
- 장바구니 → 패키지 상품 담는 경험의 연결성 강화
- 고객에게 장바구니에 담은 상품의 subset으로 패키지 상품이 취급될 수 있는 기반을 강화

## 가설
노출 조건을 "미추가 상품 존재 시 항상 노출"로 변경하면, 넛징 노출 빈도가 증가하여 패키지 상품 추가와 GMV가 개선될 것이다.

## 해결 방향
- **A(Control)**: 장바구니에 신규 상품이 들어오면 한 번만 노출
- **B(Treatment)**: 장바구니에서 안담긴 상품이 있다면 계속 노출

## 결과 (B Winner / 롤아웃)

| 지표 | A | B | Diff | 유의성 |
|---|---|---|---|---|
| 패키지 추가 유저 전환율 | 15.03% | 15.30% | **+1.77%** | p=0.010 |
| 인당 MyPkg 추가 상품 | 0.201 | 0.219 | **+8.86%** | p<0.001 |
| 글린다 → 패키지 추가 전환 | 10.59% | 11.21% | +5.89% | p<0.001 |
| 글린다 CVR | 1.96% | 1.91% | -2.50% | p=0.241 (Neutral) |
| 전체 CVR | 36.20% | 36.26% | +0.17% | p=0.653 (Neutral) |
| KR GMV per customer | 126,641 | 125,275 | -1.08% | p=0.460 (Neutral) |

→ 패키지 추가 WIN, 가드레일 무해 → **B 롤아웃**.

## 인사이트

**패키지 추가 단계만 개선, 이후 단계(조건 달성 → 할인 체크 → 구매 클릭 → 구매)는 전부 NEUTRAL. 넛징 도달률 한계와 조건 미충족 유저 증가가 원인.**

- 넛징이 "한 번 더" 상품 추가를 유도하지만 증분 유저의 평균 추가 수는 2~3개 → F2+C5(7~8개) 미달
- 넛징 도달률: A 1.8% → B 4.0% (2.24x). 그러나 전체의 4%로 광역 GMV 이동에 불충분
- 미경험 그룹 글린다 구매자 감소(-319명)는 composition shift (가망 고객이 넛징 세그먼트로 이동) — 넛징 자체의 해는 아님

## 디자인 고려사항
1. **노출 빈도 최적화**: light(1-2회) → medium(3-5회) 전환 시 글린다 CVR 4배 점프 (5.0% → 19.6%). B 유저의 88%가 light에 머묾 → 세션/방문 단위 재노출 로직 보강 필요
2. **Heavy 유저 노출 에이징**: 6+회 노출 시 글린다 CVR 39%, 전체 CVR 70% — 넛징 없이도 구매할 고의향 유저. 노출 cap으로 UX 보호 + 넛징 신선도 유지 검토
