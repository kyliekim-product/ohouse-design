# 프로토타입 제작 메타

> 콘텐츠 피드(집구경 콘텐츠탭) 프로토타입을 **1차 → 3b 디벨롭**까지 단계별로 만든 이력. 각 단계에서 어떤 입력·도구를 썼고 무엇이 결과물이었는지, 그리고 그 단계의 핵심 발견을 정리한다. (live 프리뷰에는 최종 `3b` 피드만 노출하고, 제작 이력은 여기 문서로 둔다.)

## 단계별 요약

| 단계 | 일자 | 범위 | 결과물 |
|---|---|---|---|
| **1차** | 2026-04-23 | 단일 모듈 (Landscape Card 1개) | HTML (가짜 ODS — styled div) |
| **2차** | 2026-04-24 | 단일 컴포넌트 (Landscape Card 1개) | React + 진짜 ODS 컴포넌트 |
| **3a 초안** | 2026-04-27 AM | 피드 한 판 (Top + 6 Section + Interest Feed) | React + ODS 피드 한 판 (자동 1차 출력) |
| **3b 디벨롭** | 2026-04-27 PM | 동 위, 디테일 디벨롭 | React + ODS 피드 한 판 (디테일 정합) |

## 단계별 상세

### 1차 — 2026-04-23
- **입력**: Figma (raw, 정리 전) · 노드 ID 기반 직접 조회
- **결합 계층**: ✅ Figma MCP · ✅ 트랙 Context MD · ❌ ODS MCP · ❌ O!Slice 플러그인
- **결과물**: HTML (가짜 ODS — styled div)
- **핵심 발견**: 동작·정책 규칙 OK · 그러나 ODS API 정합성 검증 불가, 트랙 Context MD 거짓 발견 불가

### 2차 — 2026-04-24
- **입력**: Figma (raw) · ODS 컴포넌트 카탈로그 조회
- **결합 계층**: ✅ Figma MCP · ✅ 트랙 Context MD · ✅ ODS MCP · ❌ O!Slice 플러그인
- **결과물**: React + 진짜 ODS 컴포넌트
- **핵심 발견**: author-info.md "Badge expert variant"가 ODS에 부재함을 자동 발견 → 트랙 Context MD 자기검증 첫 사례

### 3a 초안 — 2026-04-27 AM
- **입력**: 🆕 O!Slice 정리본 Figma (Workflow_Test, 레이어 이름·구조 표준화)
- **결합 계층**: ✅ Figma MCP · ✅ 트랙 Context MD · ✅ ODS MCP · ✅ O!Slice 플러그인
- **결과물**: React + ODS 피드 한 판 (자동 1차 출력)
- **핵심 발견**: 레이어 마커 🌀/🟣/🪩 자동 인식으로 비ODS 컴포넌트 분리 가능. 그러나 8건 디테일 미스매치 발생 → 사용자 지적 필요

### 3b 디벨롭 — 2026-04-27 PM
- **입력**: 3a 결과물 + 사용자 피드백 8건
- **결합 계층**: ✅ Figma MCP · ✅ 트랙 Context MD · ✅ ODS MCP · ✅ O!Slice 플러그인 · ➕ 사용자 피드백 루프
- **결과물**: React + ODS 피드 한 판 (디테일 정합)
- **핵심 발견**: 사용자가 일일이 지적한 디테일을 워크플로우 약점 5종으로 일반화 → 다음에 자동화로 대체 가능한 체크리스트 도출
