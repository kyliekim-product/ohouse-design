📋 htmlviaTrueSource Bookmarklet

아무 HTML 페이지에서나 클릭 한 번으로 prototype 생성을 위한 데이터를 추출합니다.

📋 추출하기
⬆️ 이 버튼을 Chrome 북마크바로 드래그하세요

설치 방법

Step 1. Chrome 북마크바를 켜세요 (⌘+Shift+B)
Step 2. 위의 "📋 추출하기" 버튼을 북마크바로 드래그하세요
Step 3. (선택) 북마클릿 이름을 알아보기 쉽게 변경 (예: "🧪 Prototype 추출")

사용 방법

  1. 분석하려는 페이지를 Chrome으로 열기
  2. 북마크바의 📋 추출하기 클릭
  3. 페이지가 자동으로 스크롤되며 lazy-loaded 이미지가 로드됨 (1-2초)
  4. 완료 alert 표시 + extraction-{slug}.json 파일이 Downloads로 다운로드됨
  5. Claude Code 세션에서 다음 명령:
    "북마클릿 추출 데이터로 {slug} 프로토타입 만들어줘"
  6. Claude Code가 JSON을 읽고 spec.md → prototype.html → QA까지 자동 실행
주의: 로그인 페이지 등 인증이 필요한 페이지도 본 브라우저의 세션이 살아있는 상태에서 클릭하면 데이터 추출 가능합니다 (Playwright는 별도 세션이라 인증 필요한 페이지를 캡처할 수 없습니다).

설치 검증 (Playwright 자동)

전체 설치가 정상인지 확인하려면 Claude Code 새 세션에서:

"랜딩 프로토타입 설치 검증해줘"

Playwright가 자동으로 5단계 점검을 실행합니다 — 사전 조건 · 추출 API 호출(무인증+키) · worked example 렌더 · 인터랙션 동작 · 북마클릿 추출 로직. 새 머신·재설치 후 1회 권장.

추출 API 키 (선택)

URL 모드(모드 A)에서 추출 API를 호출할 때 키 없이도 20 RPM으로 동작합니다. 자주 사용한다면 무료 키(500 RPM + 1천만 토큰)를 발급받아 등록하면 빠릅니다.

자동 셋업:

bash ~/.claude/skills/htmlviaTrueSource/setup-jina.sh

위 명령은 다음을 처리합니다:

  • API 대시보드 자동 오픈
  • 키 입력 (입력 숨김)
  • macOS는 Keychain, Linux/WSL은 ~/.env.jina에 저장
  • shell rc(.zshrc/.bashrc)에 자동 로드 라인 추가 (옵션)
  • 키 동작 smoke test

추출되는 데이터

  • 토큰: 사용된 색상·배경·폰트사이즈·weight·radius·letter-spacing·font-family
  • 이미지: <img> + background-image + srcset (CDN URL 그대로)
  • 구조: H1/H2/H3, section text+높이, 버튼 텍스트+aria-label
  • 임베디드 데이터: __NEXT_DATA__, Apollo/Redux state, JSON scripts, ld+json
  • 메타: URL, title, viewport, captured_at, pageHeight

제한사항

  • iframe 안 컨텐츠는 추출 불가 (브라우저 same-origin 정책)
  • Canvas/WebGL 렌더링 콘텐츠 추출 불가
  • Shadow DOM은 부분적으로만 추출됨
  • 로그인 페이지 등에 단발성 토큰이 포함된 경우 JSON에 그대로 들어갈 수 있음 — 공유 전 확인

워크플로우 다이어그램 
[Chrome 페이지]
    │
    ├─► 북마클릿 클릭
    │    │

    │    └─ extraction-{slug}.json 다운로드

[Claude Code]
    │
    │  "북마클릿 추출 데이터로 {slug} 프로토타입 만들어줘"
    │
    ├─► JSON 읽기
    ├─► spec.md 생성 (토큰·구조)
    ├─► assets.json 생성 (이미지 URL)
    ├─► data.json 생성 (embedded data)
    ├─► prototype.html 생성 (self-contained)
    └─► QA 자동 실행 (Playwright + 비교 + qa.md)
