# HelperText

입력 필드 아래에 도움말, 에러 메시지, 글자수 카운터를 표시하는 컴포넌트입니다.

> **관련 컴포넌트**
> - 입력 필드 위의 제목 → [Label](../label/guide.md)
> - Label + Input + HelperText 조합 → FormField (Notion 스펙 참고)

## Usage Guidelines

### 도움말 메시지 (Description)

입력 방법이나 조건을 안내합니다. 입력 전에 미리 보여주어 사용자의 실수를 줄입니다.

| | 예시 |
|---|---|
| ✅ | "영문, 숫자, 특수문자 포함 8자 이상" |
| ✅ | "다른 사용자에게 공개됩니다" |
| ✅ | "하이픈(-) 없이 숫자만 입력해주세요" |
| ❌ | "올바르게 입력해주세요" — 구체적 조건이 없어 도움이 안 됨 |

- 도움말은 간결하게 1문장으로 작성합니다.
- 모든 입력 필드에 도움말이 필요한 것은 아닙니다. 입력 방법이 자명한 경우 생략합니다.

![도움말 메시지 예시](./images/description.png)

### Error 메시지

유효성 검증에 실패했을 때 도움말 대신 에러 메시지가 표시됩니다. 입력 필드의 error 상태와 함께 사용합니다.

| | 예시 |
|---|---|
| ✅ | "올바른 이메일 형식을 입력해주세요" |
| ✅ | "이미 사용 중인 닉네임입니다" |
| ✅ | "최소 10자 이상 입력해주세요" |
| ❌ | "입력 오류" — 원인이 불분명 |
| ❌ | "입력값이 유효하지 않습니다. 다시 확인해주세요." — 불필요하게 김 |

- Error가 활성화되면 Description 대신 에러 메시지가 표시됩니다. 두 메시지가 동시에 표시되지 않습니다.
- 에러 메시지는 **원인과 해결 방법**을 함께 안내합니다.

![Error 메시지 예시](./images/error.png)

### 글자수 카운터 (Counter)

현재 입력 글자수와 최대 글자수를 "현재/최대" 형태로 표시합니다.

- 카운팅 기준은 Unicode Extended Grapheme Cluster(UAX #29)입니다. 이모지(👨‍👩‍👧‍👦)도 1자로 카운트합니다.
- 카운터는 HelperText의 우측에 표시됩니다.
- 도움말 메시지와 카운터를 동시에 표시할 수 있습니다.

| 사용 예시 | 형태 |
|---|---|
| 상품 후기 | "42/500" |
| 닉네임 | "8/20" |
| 한줄평 | "35/100" |

- 카운터는 순수 표시 용도입니다. 최대 글자수를 초과해도 자동으로 에러 스타일이 적용되지 않습니다. 에러 처리는 별도로 error 상태를 활성화해야 합니다.

![Counter 예시](./images/counter.png)

---

### Description + Counter 조합

도움말 메시지와 카운터를 함께 사용할 수 있습니다.

| | 예시 |
|---|---|
| ✅ | 좌측 "특수문자 사용 불가" + 우측 "8/20" |
| ✅ | 좌측 "최소 10자 이상" + 우측 "5/500" |
| ❌ | 카운터만 단독 사용하면서 도움말이 필요한 경우 — 함께 사용 |

![Description + Counter 조합 예시](./images/combination.png)

## Figma

### 프로퍼티

| 프로퍼티 | 타입 | 설명 |
|---|---|---|
| Description | Variant | `true` / `false` — 도움말 텍스트 표시 |
| Error | Variant | `False` / `True` — 에러 상태 |
| Counter | Variant | `true` / `false` — 글자수 카운터 표시 |
| max | Boolean | 최대 글자수 표시 |
| Help Text | Text | 도움말/에러 메시지 텍스트 |
