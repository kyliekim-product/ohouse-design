# Dialog

사용자에게 정보를 안내하거나 선택을 제공할 때 사용합니다. Close Button(×)이 항상 포함되어 있어 사용자가 자유롭게 닫을 수 있습니다.

> 사용자가 반드시 선택해야 하는 상황에서는 [Alert Dialog](../alert-dialog/guide.md)를 사용하세요.

## 렌더링 정책

Dialog를 어디서 렌더할지는 **트리거 위치**에 따라 결정합니다.

| 트리거 위치 | UI | 렌더 방식 | 예시 |
|---|---|---|---|
| Toolbar (네이티브) | ActionSheet, 시스템 메뉴 | 네이티브 | 더보기 메뉴, 공유, 신고 |
| Body (웹뷰/네이티브) | Dialog, Bottom Sheet | ODS | 쿠폰 안내, 정보 안내, 이벤트 |
| OS 레벨 | Permission, 시스템 Alert | 네이티브 | 카메라 권한, 알림 권한 |
| Web (브라우저) | Toolbar 대응 메뉴 | ODS | 네이티브 없으므로 ODS로 대체 |

> Toolbar는 네이티브 클라이언트에서 렌더하고, Body 영역은 웹뷰에서 렌더하는 구조를 따릅니다. Toolbar에서 트리거되는 ActionSheet는 네이티브로 호출하여 Liquid Glass 등 OS 스타일에 자동 대응합니다.

## 구조

```
Dialog
├── Close Button (×)  ← 항상 표시
├── Title             ← optional, 좌측 정렬
├── Body              ← 본문 텍스트 또는 커스텀 콘텐츠 (이미지 등)
├── Sub Text          ← optional, 보조 설명
└── Button            ← Single / Horizontal 2Button / Vertical 2Button
```

## Close Button

- 항상 표시됩니다. 제거할 수 없습니다.
- 사용자는 Close Button 또는 외부 영역 탭으로 Dialog를 닫을 수 있습니다.

### 스타일

Body 영역에 이미지, 동영상 등 다양한 콘텐츠가 올 수 있으므로, 어떤 배경 위에서도 가시성이 확보되어야 합니다.

| 요소 | 값 |
|---|---|
| 원형 배경 | `#FFFFFF`, opacity **70%** |
| × 아이콘 | 텍스트 컬러 (어두운 색) |

| 배경 | 결과 |
|---|---|
| 흰색 (기본 Dialog) | 원형 배경이 흰색에 녹아들어 × 아이콘만 보임 |
| 어두운 이미지 | 반투명 흰색 원이 밝은 영역을 만들어 × 가시성 확보 |
| 밝은/다채로운 이미지 | 원이 색을 희석시켜 깨끗한 영역 확보 |

## Usage Guidelines

### Title

- 좌측 정렬합니다.
- 문장 형태는 사용하지 않습니다. 구체적 명사나 키워드만 사용합니다.
- 반드시 한 줄로 작성합니다.
- 이모지, 아이콘, 특수기호는 사용하지 않습니다.
- 텍스트 영역이 2문장 이내이고, 타이틀과 내용이 같다면 타이틀은 생략합니다.

### Body

- '해요체'의 문장을 사용합니다.
- 아이콘, 이모지를 사용하지 않습니다.
- 2버튼 사용 시, 3줄 이내로 작성하는 것이 가장 적절합니다.
- 3줄까지는 중앙정렬, 4줄부터는 좌측정렬을 사용합니다.
  - 자동 줄바꿈되므로 임의로 줄바꿈하지 않습니다.

### Sub Text

- 텍스트만으로는 설명이 부족할 시에만 사용하며, 되도록 사용하지 않는 것을 권장합니다.
- 1줄 이내로 핵심 내용만 간결하게 작성합니다.
- 문장 앞에서 특수기호(*, ·)나 이모지를 붙이지 않습니다.
- 텍스트와 문장기호, /, > 만 사용합니다.

### Button

- 상황에 따라 3가지 타입을 사용할 수 있습니다.
  - **Single (1Button)**: 확인, 닫기 등 단일 액션
  - **Horizontal (2Button)**: 두 가지 선택지를 나란히 배치
  - **Vertical (2Button)**: 버튼의 글자수가 띄어쓰기를 포함하여 6자 이상일 경우 사용

## Specs

### Size

- App은 300 사이즈를 사용합니다.
- 화면 좌우에 10 여백을 확보한 상태로 디바이스 너비에 따라 자동 확장되며, 최대 너비는 300을 초과하지 않습니다.
- Web은 해상도에 따라 300/400/500 사이즈 사용 가능하도록 정의되어 있습니다.

### Height

- Max Height는 별도로 지정되어 있지 않으며, 필요한 경우 해당 과업에서 별도 정의해 적용합니다.

## Figma

### 프로퍼티

| 프로퍼티 | 타입 | 설명 |
|---|---|---|
| Title | Boolean | 타이틀 표시 여부 |
| Sub Text | Boolean | 보조 텍스트 표시 여부 |
| Body Text | Text | 본문 텍스트 내용 |
| Children | Slot | 본문 영역 커스텀 콘텐츠 (이미지 등) |

> Close Button은 프로퍼티가 아닙니다. 항상 표시되며 제거할 수 없습니다.

### Viewport 통합

기존에 Mobile/Tablet/PC 3개 Viewport variant로 분리되어 있었으나, 실질적 차이가 너비뿐이므로 단일 컴포넌트로 통합했습니다. 필요 시 인스턴스 너비를 조절하여 사용합니다.

### Private Sub-Components

| sub-component | 용도 |
|---|---|
| .Dialog Title | Dialog 전용 타이틀 |
| .Dialog Button | Dialog 전용 버튼 영역 |
