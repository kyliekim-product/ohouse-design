### 플랫폼별 지원

| 플랫폼 | UGC(콘텐츠) | UGC(댓글) | 사용자 신고 |
|-------|-----------|----------|-----------|
| Android | ✅ 신고 | ✅ 신고 | ✅ "신고하기" |
| Web | ✅ 신고 | ✅ 신고 | ✅ "숨기기" |
| iOS | ❌ **없음** | ❌ **없음** | ❌ **없음** (타 플랫폼 처리 결과만 동기화) |

> **중요**: iOS는 신고 기능 자체가 없음. Android는 구글 심사 이슈로 "신고하기", Web은 동일 기능을 "숨기기"로 표현.

### UGC 신고 (콘텐츠)

- **처리**: 피드 신고 시 **즉시 차단** → 해당 콘텐츠 미노출 or 블라인드 처리
- **지속성**: 사용자/콘텐츠 차단 정보 필터링 → 앱 데이터 삭제·재설치해도 신고한 계정에서 계속 미노출
- **적용 화면**: 추천 / 고정토픽탭 / 집들이 / 집사진 / 이벤트 페이지 등 (24Y1M 기준 완료)

**해제 방법**:
- 인하우스 API: `block.v1.BlockService/DeleteBlock`
- 콘텐츠 어드민 > '사용자 차단 관리' 메뉴
- Android 한정 추가: **앱 데이터 삭제 or 재설치** (로컬 저장 때문, [OHSAND-7226](https://ohouse.atlassian.net/browse/OHSAND-7226))

### UGC 신고 (댓글) — 플랫폼별 로직 다름

| 항목 | Android | Web |
|------|---------|-----|
| 처리 트리거 | 1회 신고 즉시 | 다른 계정 & 동일 사유 **5회 누적** |
| 처리 범위 | 단말 한정 (A단말 A계정 신고 시만) | 서버 처리, **전체 숨김** |
| B단말에서 A계정 로그인 시 | 블라인드 X | 블라인드 O |
| 해제 | 앱 데이터 삭제·재설치 | 어드민 '기각' 처리 |

### 사용자 신고 (유저홈 기준)

- Android: **"신고하기"** / Web: **"숨기기"** (명칭 다름, 기능 같음)
- 해당 유저가 작성한 UGC **전체 숨김** 처리
- 로컬+서버 모두 처리 → 다른 플랫폼 로그인 시에도 해당 유저 UGC 미노출

**해제**:
- Web: 설정 > 사용자 숨기기 설정 > '숨기기 해제'
- Android: Web에서 해제 후 앱 데이터 삭제·재설치

### 커머스 영역 신고 (PDP 리뷰·문의, 스타일링샷, 브랜드홈)

- 신고 유저에게만 해당 콘텐츠 **즉시 숨김**
- **어드민 조절 불가** (콘텐츠 어드민에서 승인/기각 처리 안 됨)
- 담당: 커머스 트랙 (콘텐츠 트랙 아님)

### 어드민 검수 워크플로우

- 콘텐츠 어드민 > 신고관리 메뉴 (contents-admin)
- 승인/기각 처리 시 신고한 사용자 **외 모든 사용자**에게 반영
- **검수 가능 UGC**: 집들이(전문가 집들이), 노하우, 사진(다중사진), 동영상, 질문과답변, 댓글(대댓글), 시공리뷰
- **검수 불가능 UGC**: 상품리뷰, 상품문의 (이건 커머스 관할)
- **자동 숨김 트리거**: 다른 계정 & 동일 사유 **5회 누적** 시 자동 숨김 리스트 추가
- 자동 숨김 해제: 해당 리스트 or 신고 리스트 중 1개 해제 시 전체 해제

## LLM 작업 주의사항 (신고·차단 관련)

- ⚠️ **iOS에는 신고 기능 없음** — iOS 전용 화면 설계 시 신고 UI 넣지 말 것
- ⚠️ **Android "신고하기" / Web "숨기기"** — 플랫폼별 문구 달라야 함 (구글 심사 이슈). 통일하지 말 것
- ⚠️ **댓글 신고 처리가 Android/Web 다름**:
  - Android = 1회 즉시 + 단말 한정
  - Web = 5회 누적 + 서버 전체 숨김
- ⚠️ **상품리뷰·상품문의는 콘텐츠 어드민에서 승인/기각 불가** — 커머스 영역 정책 참조
- ⚠️ **신고 즉시 반영**: 24Y1M 이후 1회 신고 즉시 미노출. 과거 5회 누적 방식으로 가정하지 말 것
- ⚠️ **커머스 영역 신고는 어드민 조절 불가** — 신고 유저 기준 숨김만
