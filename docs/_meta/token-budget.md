## ✂️ 절약 전략 5가지

### 1. INDEX 먼저, 상세는 나중
폴더 들어가면 `README.md` 또는 `INDEX.md`부터. 그다음 필요한 파일만.

### 2. Frontmatter 체크
파일 상단 `when-to-read` 확인. 안 맞으면 스킵.

### 3. `meta.yaml` 우선, `guide.md` 나중
meta.yaml은 토큰 밀도 최고 (id/aliases로 검색). spec.md는 공식 명세, guide.md는 가이드·예시. 사용법 질문이면 spec.md까지로 충분.

### 4. 같은 도메인 컨벤션 활용
`domains/<도메인>/`에서 이미 만든 화면 1~2개 참고. 새 화면 만들 때 처음부터 만들지 않음.

### 5. 마커 활용
이미 생성된 코드에 `@ods-component:Button` 마커 있으면 Button 재조회 불필요.

## 🚨 예산 초과 신호

세션 내 다음 중 하나면 **중단 후 재계획**:

- 같은 파일 2번 로드
- 다른 도메인 폴더 접근
- `_archive/` 진입
- Tier 5 파일 3개 이상 로드 (요청 없이)
- 전체 토큰 20k 돌파
